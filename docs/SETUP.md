# Setup Script for CSN Object Visualizer

This script automates the setup process for the CSN Object Visualizer.

## Usage

```bash
chmod +x setup.sh
./setup.sh
```

Or on Windows:
```cmd
setup.bat
```

## What it does

1. Creates virtual environment
2. Activates it
3. Installs dependencies
4. Verifies installation
5. Provides next steps

For manual setup, see README.md
